# 008: Портирование на GNOME Shell 45–50 (ESM) и legacy-заморозка 42–44

- Статус: **готово** (Ф0–Ф4; 2026-10-29; загрузка на EGO — вручную
  пользователем)
- ADR: [0006-gnome-45-50-port](../../adr/0006-gnome-45-50-port.md)
  (accepted, 2026-10-24)
- Ветка: `feat/gnome-45-50-port`

## Цель

Расширение публикуется на EGO двумя релизами под собственным uuid
`notes@escator` (ADR-0006 п. 5, решение 2026-10-24 — см. журнал:
авто-обновлятель EGO сносит расширения с uuid апстрима, чужой zip
опубликовать нельзя): замороженный legacy-релиз (42–44, тег `v2.1`,
влит в master) и портированный на формат GNOME Shell 45+ (ESM, классы
`Extension`/`ExtensionPreferences`) — заявленный на 45–50 по факту CI.
Функциональность и форматы данных не меняются. Тестирование 45+ — через
[gnome-shell-pod](https://github.com/Schneegans/gnome-shell-pod) (контейнеры
xvfb с каждой версией Shell).

## Пользовательский сценарий (приёмка)

1. Legacy-релиз: `metadata.json` → `["42","43","44"]`, тег `v2.1`, zip
   собирается; ставится на 42.9 и проходит живой смок (значок панели,
   toggle с задержкой 006, двойной клик, фильтр 004, «Новая из буфера»,
   prefs со всеми вкладками).
2. Контейнер 45–50 (каждая заявляемая версия): zip устанавливается и
   включается, journal без ошибок расширения.
3. Контейнер: значок панели появляется, одиночный toggle работает, заметка
   создаётся, редактируется, сохраняется и перечитывается после рестарта
   shell; «Новая из буфера», меню правым кликом; prefs открываются, все
   вкладки (Settings/Backup/Help/About) переключаются, настройка
   сохраняется.
4. CI: workflow на GitHub Actions зелёный на матрице заявленных версий
   (установка + enable + gjs-смок под GJS контейнера).
5. `metadata.json` порт-релиза: `shell-version` — ровно версии с зелёным
   CI; `version` — целое (правила EGO, числа фиксируются при загрузке);
   uuid — `notes@escator`, авто-обновлятель EGO установку больше не трогает.
6. Локальный gjs-смок-набор зелёный после перевода на ESM.
