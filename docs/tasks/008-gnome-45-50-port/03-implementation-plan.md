## Ф4. Релиз

- **Шаг 1. Переезд на свой uuid `notes@escator` (ADR-0006 п. 5, решение
  2026-10-24; переезжают ОБЕ линии).** Причина: авто-обновлятель EGO сносит
  расширения с uuid апстрима (downgrade = тоже обновление), а загрузить
  zip под чужим uuid на EGO невозможно — без переезда 42–44-версии
  публиковаться негде. Механика:
  - `git mv notes@maestroschan.fr notes@escator` на feat-ветке; metadata:
    `uuid` → `notes@escator`, снять `_generated` (`url` остаётся);
  - пути: `build-a-zip.sh` (EXT_ID), `update-and-compile-translations.sh`,
    `POTFILES.in`, импорты в `test/` (включая заголовки юнит-тестов),
    упоминания в README/user-help; `install.sh` не трогается (имя каталога
    берёт сам);
  - `Common.DATA_PATH` НЕ меняется: заметки, layouts.json, gsettings
    остаются на месте;
  - локальный переезд: rm старого каталога расширения, установка нового,
    enable нового uuid; правило чистки `extension-updates/` становится
    ненужным;
  - гейт: юнит+смок зелёные на переименованном дереве, живая проверка на
    42.9 (иконка, toggle), после рестарта шелла staging
    `extension-updates/notes@escator` НЕ появляется;
  - заморозка 42–44: cherry-pick коммита переезда на master, пересборка
    legacy-zip из содержимого тега + переезд (код идентичен v2.1).
- `metadata.json` порт-релиза: `shell-version` = версии с зелёным CI
  (сценарий 5); `version` — целое по правилам EGO, возрастающее по мере
  загрузок (конкретные числа фиксируются при загрузке; рекомендация:
  legacy = 2, порт = 3 — читается как продолжение 2.1 → 3.0; «3.0» —
  маркетинговое имя в README/About). zip; merge `--no-ff` в dev; пуш.
- Загрузка на EGO — вручную пользователем, одна новая страница
  `notes@escator`, multi-versioning раздаёт обе версии: legacy (≤44) и
  порт (45+).

## Риски и открытые вопросы

- Вёрстка About в Adw-окне (496×405) может поехать — правки размеров/CSS
  допустимы в Ф2, это не редизайн.
- Ход `fillPreferencesWindow` (47+) — async; не забыть `await`-семантику.
- Образа gnome-shell-pod для какой-то версии может не быть → версия не
  заявляется (ADR-0006).
- Wayland/контейнерные нюансы (фокус, буфер) живьём не проверяются —
  принимается уровень CI-смока; живая приёмка опциональна на VM.
- Стабы resource:// в харнессе — 02 §5.
