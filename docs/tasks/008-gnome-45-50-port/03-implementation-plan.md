## Ф1. ESM shell-часть

По файлам:

- `extension.js`: класс `Extension` (02 §2); `init()` → поля класса;
  импорты `resource:///…`; Mainloop → GLib (все 6 таймерных точек);
  `openPreferences()`; разрыв цикла с noteBox.
- `noteBox.js`, `menus.js`: относительные импорты, `resource:///…` для
  ui/misc-модулей; зависимости параметрами; `Signals` из
  `…/misc/signals.js`.
- `dialog.js`: `resource:///org/gnome/shell/ui/modalDialog.js`.
- `layouts.js`: `TextDecoder` вместо `byteArray`.
- `common.js`, `textHistory.js`: только синтаксис ESM (`export`), логика
  не трогается.
- `Gettext` — 02 §3.

Зелёность: смок-харнесс в новой форме зелёный под локальным gjs (полный
объём — Ф3, здесь достаточно чистых модулей: layouts + textHistory).

## Риски и открытые вопросы

- Вёрстка About в Adw-окне (496×405) может поехать — правки размеров/CSS
  допустимы в Ф2, это не редизайн.
- Ход `fillPreferencesWindow` (47+) — async; не забыть `await`-семантику.
- Образа gnome-shell-pod для какой-то версии может не быть → версия не
  заявляется (ADR-0006).
- Wayland/контейнерные нюансы (фокус, буфер) живьём не проверяются —
  принимается уровень CI-смока; живая приёмка опциональна на VM.
- Стабы resource:// в харнессе — 02 §5.
