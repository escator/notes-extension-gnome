# 005: Разворачивание заметки двойным кликом

- Статус: **planned** — документация и план готовы (2026-10-23), имплементация
  позже
- ADR: [0004-note-expand-toggle](../../adr/0004-note-expand-toggle.md)
  (accepted, 2026-10-23)
- Ветка: `feat/note-expand` (документация — первый коммит ветки; по правилам
  AGENT.md)

## Цель

Двойной клик по области перемещения заметки (moveBox, «пустое» место шапки)
разворачивает заметку так, чтобы был виден весь текст; повторный двойной клик
сворачивает её обратно. Это замена скроллингу для беглого просмотра контента,
не вошедшего в окно; работает в обоих режимах (read-only и редактирование),
без требования фокуса.

Подход сознательно обходит известный баг natural-size (ClutterText в GNOME 42
не пересчитывает natural height при автопереносе): нужная высота вычисляется
явным замером `get_preferred_height(ширина)` (он корректен), а смена fixed
size актора форсирует полный deep relayout — см.
[01-analysis.md](01-analysis.md).

Решения пользователя от 2026-10-23 — в [02-architecture.md](02-architecture.md).

## Пользовательский сценарий (приёмка)

1. Заметка, чей текст не влезает в окно. Двойной клик по области перемещения
   шапки → заметка плавно (~0,25 с) разворачивается: весь текст виден,
   развёрнутая форма держит пропорцию 3:4 (высота = 4/3 ширины).
2. Повторный двойной клик → плавное сворачивание к точному исходному размеру
   и позиции.
3. Двойной клик по заметке, где весь текст уже виден → ничего не происходит.
4. Развёрнутая заметка + клик по другой заметке (или любое действие,
   вызывающее сохранение раскладки) → в `layouts.json` записан исходный
   (домашний) размер, не развёрнутый.
5. Ручной resize развёрнутой заметки → размер сохранён по обычному пути;
   последующее сворачивание возвращает к последнему ручному размеру.
6. Ручное перемещение развёрнутой заметки → позиция сохранена по обычному
   пути.
7. Развёрнутая заметка + скрыть все (toggle панели, фильтр по цвету, открытие
   настроек) → при следующем показе заметка в стартовом (домашнем) размере.
8. Правка, вставка из буфера или смена размера шрифта в развёрнутом виде →
   размер пересчитывается живьём (без анимации), весь текст остаётся виден.
9. Заметка у нижнего края монитора разворачивается со сдвигом вверх; у
   правого края — со сдвигом влево; края не выходят за пределы монитора.
10. Защита максимума (не штатный режим): текст больше экрана / крошечный
    монитор → разворот ограничен прямоугольником монитора (ширина ≤ ширины
    монитора, высота ≤ высоты; пропорция 3:4 может быть нарушена по высоте);
    невлезающий хвост текста остаётся скрытым.
11. Оба режима: разворот работает в read-only и в редактировании; двойной
    клик не запускает перетаскивание; перетаскивание посреди анимации не
    рвёт геометрию; смена мониторов в развёрнутом виде (xrandr) сворачивает
    заметку и раскладывает раскладку чисто, развёрнутый размер на диск не
    утекает.
12. Двойной клик по кнопке изменения размера (дополнение от 2026-10-23) →
    заметка принимает стартовый размер новой заметки (300×180) в текущей
    позиции, с анимацией; развёрнутый режим этим завершается; размер
    сохраняется (проверка layouts.json — после Ф3).
