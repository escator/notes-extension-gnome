# 006: Новая заметка двойным кликом по значку панели

- Статус: **in progress**
- ADR: [0005-click-actions](../../adr/0005-click-actions.md) (accepted, 2026-10-23)
- Ветка: `feat/click-actions` (общая с 007; документация — первый коммит ветки)

## Цель

Двойной клик по значку расширения в панели создаёт новую заметку (заметки
при этом показаны, новая — в режиме редактирования, цвет — активного фильтра).
Одиночный клик сохраняет смысл основного toggle; сосуществование кликов —
через задержку одиночного на таймаут двойного (решение пользователя
2026-10-23, см. [02-architecture.md](02-architecture.md)).

## Пользовательский сценарий (приёмка)

1. Одиночный клик по значку: заметки показываются/скрываются с задержкой
   ~таймаут двойного клика системы (без визуальных артефактов в момент
   клика).
2. Двойной клик при скрытых заметках: отложенный toggle отменяется (без
   моргания), заметки показаны и создана одна новая заметка в режиме
   редактирования.
3. Двойной клик при видимых заметках: скрытия не было, существующие заметки
   не мигают, создана одна новая заметка в режиме редактирования; раскладка
   сохранена.
4. Правый клик: меню открывается как раньше; отложенный одиночный клик
   отменён и после закрытия меню не срабатывает.
5. Горячая клавиша: toggle мгновенный, без задержки.
6. Одиночный клик по значку (заметки видимы), затем клик по пустому месту
   рабочего стола в пределах таймаута: подложка 007 скрывает заметки сразу и
   отменяет отложенный toggle — заметки не всплывают обратно через ~0,4 с.
7. Двойной клик при активном цветовом фильтре: новая заметка цвета фильтра
   и видима (инвариант видимости 004).
8. Случайный третий клик сразу после двойного: ведёт себя как новый
   одиночный (отложенный toggle сработает через таймаут); пачка заметок не
   создаётся.
9. `disable()` с неотработавшим отложенным toggle: таймер снят, ошибок нет.
