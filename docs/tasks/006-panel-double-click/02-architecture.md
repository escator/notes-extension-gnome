# 02 Архитектура: двойной клик по значку панели

## Решение пользователя (2026-10-23)

Из двух способов сосуществования одиночного и двойного клика выбрана
**задержка одиночного**: одиночный клик срабатывает через таймаут двойного,
двойной отменяет его и создаёт заметку. Отклонённый вариант «мгновенный
toggle с откатом второго клика» отбракован из-за моргания заметок в паре.

## Модель

- Новое состояние менеджера: `_pendingToggleId` (id GLib-таймаута или null).
- Таймаут = `Clutter.Settings.get_default().double_click_time` (мс, берётся
  из системной настройки скорости двойного клика), фолбэк 400.
- `_onButtonPressed`:
  - правая кнопка → `_cancelPendingToggle()` + меню (как раньше);
  - левый клик: если пара уже открыта (`_pendingToggleId != null`) →
    отменить таймер и вызвать `_onButtonDoublePressed()`; иначе открыть
    пару — запланировать `_toggleNotes()` на таймаут;
  - `event === null` (горячая клавиша) → `_cancelPendingToggle()` +
    мгновенный `_toggleNotes()`.
- `_toggleNotes()` начинается с `_cancelPendingToggle()` — единая точка,
  страхующая все входы (клавиатура, dismissal 007).
- `_onButtonDoublePressed()`: ленивая загрузка, `createNote` цвета активного
  фильтра в режиме редактирования (`startInEditMode = true`, как «Новая
  заметка» меню), затем `_showNotes()`, если заметки ещё не видимы. Существующий
  toggle-счётчик не трогается: никакого скрытия в паре не происходит.
- `_cancelPendingToggle()`: `Mainloop.source_remove` + `null`.
- `destroy()`: снять таймер по образцу `_monitorsDebounceId`.

## Семантика лишних кликов

Каждый нечётный клик открывает новую пару, каждый чётный в пределах окна
создаёт заметку. Тройной клик после двойного = отложенный toggle (сценарий
006-8): никаких каскадов создания.

## Альтернативы (отклонены)

- `event.get_click_count()` от Clutter: распознавание пары силами Clutter,
  но задержку одиночного всё равно пришлось бы держать самому; собственный
  таймер проще и тестируется харнессом без эмуляции click_count.
- Мгновенный toggle с откатом: моргание (см. выше).
