# 03. План реализации: собственные клавиатурные текстовые действия

Ветка `feat/text-context-menu` (продолжение). Каждая фаза заканчивается
рабочим состоянием и одним логическим коммитом; живые проверки — на X11.

## Фазы

### Ф1 — Общий слой действий (рефакторинг без смены поведения)

`noteBox.js`:

- Новые методы по 02 §1: `copySelection()`, `cutSelection()`,
  `pasteClipboardAtCursor()`, `selectAllText()` — перенести реализации из
  `menus.js` (`_onCutActivated`/`_onCopyActivated`/`_onPasteActivated`/
  `_onSelectAllActivated`), включая guard уничтоженной заметки в async-колбэке
  и `boundary()` до мутаций.
- `undo()/redo()` остаются как есть.

`menus.js`:

- `_on*Activated` делегируют методам `NoteBox`; локальные реализации удалить.

DoD (живая проверка): меню работает как раньше — сценарии 1–3 задачи 002;
юнит-тесты зелёные (51/51, 69/69); синтаксис обоих файлов.

### Ф2 — Полный клавиатурный перехват

`noteBox.js`:

- `_onKeyPress` переписать по матрице 02 §2: matching по 02 §3 (keyval ИЛИ
  hardware keycode, константы кодов с комментарием), все распознанные клавиши
  → `EVENT_STOP`, действия — методы Ф1 и `undo()/redo()`; «нет выделения /
  нет текста» — тоже `EVENT_STOP`.
- Удалить затычку ed573d5 как отдельный случай — она становится частью общей
  матрицы (строки «глотается, ничего» для read-only).
- Ctrl+A добавить в перехват (сейчас — натив; в read-only не работал вовсе).

DoD (живая проверка X11): сценарии 1–5 из README 003, включая **русскую
раскладку** (Ctrl+Z/Ctrl+V при активной кириллице); регресс: обычный набор
текста не задет, Enter/стрелки работают в редактировании.

### Ф3 — Совместная приёмка 002+003, слияние

- Полная приёмка: сценарии 1–11 задачи 002 + 1–7 задачи 003; юнит-тесты.
- i18n: `update-and-compile-translations.sh --all` (msgmerge по всем языкам).
- Документация: ADR-0002 сверить с реализацией; журналы 04 обеих задач;
  индекс задач; память.
- Слияние `feat/text-context-menu` в `dev`: `--no-ff`, явное согласие
  пользователя, `git branch --merged dev` перед удалением ветки.
