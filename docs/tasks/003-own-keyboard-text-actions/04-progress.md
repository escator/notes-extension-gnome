  новая секция «text actions»: `copySelection()` / `cutSelection()` /
  `pasteClipboardAtCursor()` / `selectAllText()` — реализации перенесены из
  `menus.js` дословно (включая `boundary()` во всех четырёх, как в 002);
  async-guard вставки заменён на `this.actor == null` — собственный паттерн

  та же, что у флага меню; комментарий-обоснование про отсутствие
  clipboard-методов у Clutter.Text GS 42 переехал вместе с кодом. `menus.js` —
  пункты Cut/Copy/Paste/Select all делегируют лямбдами (как Undo/Redo с 002),
  четыре локальных `_on*Activated` удалены; `_isDestroyed` остаётся для
  чувствительности Paste в `_redisplay`. Проверки: синтаксис обоих файлов,
  юнит-тесты 51/51 и 69/69; живая проверка X11 (автоматизация xdotool +
  скриншоты, буфер читался независимым X-клиентом python3/Gdk): сценарии 1–3
  задачи 002 пройдены — выделение→«Копировать» активно→в буфере ровно

  редактирование→«Вставить» активен (буфер непуст)→вставка ровно в позицию

  данные пользователя (layouts.json, .bak, *_text) восстановлены из снапшота
  байт-в-байт, заметки скрыты, тестовая заметка 9 удалена через UI.
