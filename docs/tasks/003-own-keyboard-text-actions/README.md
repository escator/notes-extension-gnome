## Цель

Полный отказ от нативной клавиатурной обработки текстовых клавиш заметки:
Ctrl+V/Shift+Insert, Ctrl+C, Ctrl+X, Ctrl+A, Ctrl+Z, Ctrl+Shift+Z
перехватываются и исполняются теми же методами `NoteBox`, что и пункты
контекстного меню (решение пользователя 2026-10-21 после провала сценария 4
задачи 002). Мотивация и разбор багов — в [01-analysis.md](01-analysis.md).

## Пользовательский сценарий (приёмка)

1. Редактирование: Ctrl+V вставляет буфер в позицию курсора; это один шаг
   undo; Shift+Insert — то же самое.
2. Редактирование: Ctrl+C копирует выделение (вставляется в стороннее
   приложение); Ctrl+X вырезает (текст удалён и в буфере).
3. Ctrl+Z / Ctrl+Shift+Z — undo/redo в обоих режимах; **на русской
   раскладке тоже работают**.
4. Чтение: Ctrl+V и Ctrl+X ничего не делают (и не переключают режим);
   Ctrl+C копирует выделение; Ctrl+A выделяет всё; Ctrl+Z отменяет,
   например, вставку кнопкой заголовка.
5. Пункты меню и клавиши дают идентичный результат (общие методы), включая
   чувствительность: в read-only Ctrl+V/Ctrl+X — нооп, как неактивные пункты.
6. Сценарии 5–11 из [README задачи 002](../002-text-context-menu/README.md)
   проходят (undo-порции, redo, независимость заметок, меню).
7. При клине буфера mutter/X11 сценарий пережидается (известное внешнее
   ограничение, не блокирует приёмку).
