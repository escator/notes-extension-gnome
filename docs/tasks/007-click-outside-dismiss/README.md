# 007: Скрытие заметок кликом вне заметок

- Статус: **in progress**
- ADR: [0005-click-actions](../../adr/0005-click-actions.md) (accepted, 2026-10-23)
- Ветка: `feat/click-actions` (общая с 006)

## Цель

Пока заметки видимы, клик в любое место вне их области скрывает все заметки —
тот же эффект, что основной toggle. Поведение включается отдельным
toggle-переключателем в Settings (`hide-on-click-outside`, по умолчанию
включено). Механизм — невидимая полноэкранная подложка light-dismiss
(решение пользователя 2026-10-23; пассивный перехват отклонён — на X11 клики
вне chrome до shell не доходят).

## Пользовательский сценарий (приёмка)

1. Настройка включена (дефолт), заметки видимы: клик по пустому рабочему
   столу скрывает все заметки — правка завершается, сохранение происходит
   (полный путь `_hideNotes`, как toggle).
2. Клик по окну приложения при видимых заметках: заметки скрываются; сам
   клик окном не получают (съедается подложкой) — следующий клик работает
   в окне как обычно.
3. Клик по значку расширения при видимых заметках: обычный toggle (значок
   выше подложки, двойного срабатывания нет).
4. Клик по другим элементам панели (часы, системное меню): их меню
   открываются, заметки не скрываются.
5. Клик по заметке, её кнопкам и её меню: обычная работа, скрытия нет; клик
   по месту заметки, скрытой цветовым фильтром, скрывает все заметки
   (инвариант видимости 004).
6. «Настройки» в меню заметки: заметки скрыты, подложка снята, окно настроек
   кликается нормально.
7. Выключить переключатель в Settings при видимых заметках: подложка снята
   немедленно; клики по рабочему столу больше не скрывают. Включить обратно:
   поведение восстановилось.
8. Диалог подтверждения удаления / переименования: клики внутри диалога
   заметки не скрывают (модальный grab), после закрытия диалога поведение
   восстанавливается.
9. `monitors-changed` при видимых заметках: подложка накрывает все мониторы,
   клик на любом скрывает заметки.
10. Перезагрузка расширения при видимых заметках: подложка снята вместе с
    заметками, после включения менеджер стартует скрытым.
11. Отложенный toggle 006 отменяется dismissal'ом (см. 006-6).
12. Строка настройки переведена на русский; `gsettings`-ключ существует,
    дефолт `true`.
