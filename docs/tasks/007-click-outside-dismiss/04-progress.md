## Журнал

- 2026-10-23 — анализ (input region X11 по исходникам shell 42.9),
  концепция, ADR-0005, план; решение пользователя: подложка light-dismiss.
- 2026-10-23 — Ф2 реализована: gschema-ключ `hide-on-click-outside`
  (default true), `_updateClickCatcher` с прижиманием над `window_group`,
  `_dismissNotes` (отмена пары 006 + полный `_hideNotes`), сигнал
  `changed::` + строка в prefs.ui/js; smoke-фаза 7. Уроки: (а) два подряд
  `_hideNotes` затирают `_timeout_id` — в реальном shell первый таймаут
  просто срабатывает сам (утечки нет), но ручному планировщику smoke нужен
  явный дожиг save-таймаутов (`fireDeferredSave`); (б) `global` из
  extension.js в харнессе живёт на `globalThis`.
- 2026-10-24 — живая приёмка: **сценарий 1 провален** (toggle включён,
  заметки видимы, клик по пустому столу — заметки остаются). Сценарии 2–12
  не проверялись. Разбор: по gresource-исходникам shell 42.9 (`layout.js`
  этой машины) код соответствовал ожиданиям — `addChrome` ставит актор
  ниже `top_window_group`, `_updateRegions` включает видимые
  chrome-акторы в `global.set_stage_input_region`; позиционирование над
  `window_group` через `set_child_below_sibling(catcher, children[1])`
  корректно. Идея root cause не подтвердилась и не опроверглась; живой
  осмотр невозможен без Eval (вырезан из D-Bus API в 42.9), готовился
  эксперимент «xdotool-клик + журнал + xwininfo -shape». Пользователь
  остановил работу: фича слишком дорогая и может тянуть баги. Код 007
  удалён из ветки (кетчер, ключ gschema, prefs-строка, локали, README,
  smoke-фаза 7); ru вернулся к 53/53, smoke к 106/106.
