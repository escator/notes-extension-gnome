## Цель

Секция «Фильтр по цвету» в меню иконки панели: выбор одного цветового пресета
оставляет на экране только заметки этого цвета. Фильтр — временное состояние
сессии: не переживает перезапуск shell, не пишется на диск. Активный фильтр
виден цветной точкой-бейджем на иконке панели и кольцом на свотче в меню.

Решения пользователя от 2026-10-21 — в [02-architecture.md](02-architecture.md).

## Пользовательский сценарий (приёмка)

1. Правый клик по иконке панели: в меню, между «New from Clipboard» и
   «Settings», есть секция «Фильтр по цвету» — 8 свотчей (2×4, порядок как в
   меню заметки) и пункт «Сбросить фильтр» (серый, пока фильтр не активен).
2. Заметки нескольких цветов видимы. Клик по свотчу закрывает меню: на экране
   остаются только заметки этого цвета; на иконке панели появляется цветная
   точка.
3. Повторное открытие меню: выбранный свотч обведён кольцом (ring-цвет
   пресета, как у свотча текущего цвета в меню заметки); «Сбросить фильтр»
   активен.
4. Клик по выбранному свотчу повторно либо «Сбросить фильтр»: возвращаются
   все заметки, точка с иконки исчезает. Появление заметок мгновенное.
5. При активном фильтре «New note» и «New from Clipboard» создают заметку
   цветом фильтра; она сразу видна и (для «New note») в режиме
   редактирования. Без фильтра — как раньше: цвет по Settings (дефолт =
   beige).
6. При активном фильтре смена цвета видимой заметки на другой пресет в её
   меню: заметка плавно растворяется (~0,3 с, не мгновенно), успев выйти из
   редактирования; текст сохранён. Плавность — осознанное решение: скрытие
   должно читаться как реакция на смену цвета, а не как пропажа заметки.
7. Глобальный toggle при активном фильтре: скрыть все → показать — видно
   только отфильтрованное, фильтр и точка сохраняются.
8. Перезапуск shell (Alt+F2 → r): все заметки видимы, фильтра нет, точки нет.
9. Строки «Фильтр по цвету» и «Сбросить фильтр» переведены (ru), `.mo`
   перекомпилирован.
