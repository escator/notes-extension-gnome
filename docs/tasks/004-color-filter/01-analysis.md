# 01: Анализ — фильтр по цвету

Зафиксировано 2026-10-21 по чтению кода до начала реализации.

## Текущее состояние

### Меню панели

`NotesManager._buildPanelMenu` (extension.js:460–497) строит `PopupMenu`
с тремя пунктами через `_addIconAction` (extension.js:504–513): New note,
New from Clipboard, Settings. Меню открывается правым кликом
(`_onButtonPressed`, extension.js:423–432), левый — глобальный toggle.
Расширение секций уже есть: `open-state-changed` (extension.js:481–496)
обновляет чувствительность пункта Clipboard асинхронно.

Референс неинтерактивной секции со свотчами — `NoteOptionsMenu._redisplay`
(menus.js:41–87): два `PopupBaseMenuItem` с `reactive: false`, 4 кнопки
`St.Button` в каждом. Отрисовка свотча и кольца активного цвета —
`_addColorButton` (menus.js:130–153): заливка `rgb(...)`, кольцо —
`border-color: <ring>; border-width: 2px` на классе `notesCircleButton`
(stylesheet.css: `border-style: solid` обязателен, иначе рамки нет).

### Цвета

- Палитра: `PRESET_COLORS` (common.js:31–40) — 8 пресетов, у каждого
  `rgb`, `border`, `ring`.
- Цвет заметки: `NoteBox.customColor`, строка `'r,g,b'` (noteBox.js:67–75,
  записывается в `_applyColor`, noteBox.js:943). UI установки цвета — только
  пресеты (меню заметки); кастомный цвет удалён из проекта.
- Дефолт: gsettings `first-note-rgb` = `['0.9098','0.8353','0.7216']` →
  232,213,184 = **beige** из палитры; фон `.noteBoxStyle` `#E8D5B8` — тот же
  beige. То есть дефолтная заметка тоже несёт цвет пресета, и фильтр может
  быть строгим сравнением rgb-строк без категории «другое».
- Уникальный источник смены цвета в рантайме — `applyColorAndSave`
  (noteBox.js:921–924), вызывается меню заметки; после него `onlySave`.

### Видимость

Глобальная и бинарная: `_notesAreVisible` + `_showNotes`/`_hideNotes`/
`_onlyHideNotes` (extension.js:391–421, `_toggleNotes` 434–447).
Индивидуального скрытия заметки нет. Физика — `NoteBox.show`/`onlyHide`
(noteBox.js:735–743): `actor.visible` **плюс** `trackChrome`/`untrackChrome`
(освобождение input-региона). Перед глобальным скрытием `_hideNotes`
вызывает у каждой заметки `setEditMode(false)` и отложенно сохраняет текст
(extension.js:398–414).

### Создание заметок

`createNote(colorString, fontSize, startInEditMode)` (extension.js:208–228);
панель и пункт меню передают `''` → NoteBox подставляет `first-note-rgb`.
Пустой набор заметок при первом toggle тоже создаёт `''` (extension.js:440).
«New from Clipboard» создаёт заметку и заливает текст буфера
(extension.js:529–544).

### Анимации и иконка панели

Анимаций в проекте нет ни одной; Clutter 40+ даёт `actor.ease({...})` —
достаточно для fade-out. Кнопка панели — `PanelMenu.Button`, ребёнок
добавляется напрямую (`panel_button.add_child(icon)`, extension.js:74–78);
одного ребёнка можно заменить на контейнер с иконкой и точкой-бейджем.

### Переводы

Домен `notes-extension`; новые строки добавляются в POT (POTFILES.in уже
включает extension.js), затем msgmerge + компиляция `.mo` — процесс как в

## Точки расширения (все уже существуют)

| Что | Где |
|-----|-----|
| Инвариант показа | `_showNotes` — показывать только прошедших фильтр |
| Секция меню | `_buildPanelMenu`, после пункта New from Clipboard |
| Цвет новой заметки | вызовы `createNote` из меню панели (3 места) |
| Реакция на смену цвета | `applyColorAndSave` → менеджер переоценивает фильтр |
| Скрытие одной заметки | `onlyHide` + `setEditMode(false)` + `untrackChrome` (уже внутри onlyHide) |
| Бейдж | `panel_button` — контейнер вместо одиночной иконки |

## Найденные неочевидные моменты

1. **Фильтр обязан идти через `show`/`onlyHide`**, не через голый
   `actor.visible`: иначе заметка останется в input-регионе chrome и будет
   ловить клики «невидимой».
2. **Заметка в редактировании, исключаемая фильтром**, должна сначала выйти
   из него (`setEditMode(false)`), как при глобальном скрытии — иначе
   останется key focus у скрытого актора.
3. **Opacity после fade-out** надо вернуть в 255 до следующего `show`,
   иначе заметка «вернётся» прозрачной.
4. **Скрытая фильтром заметка не интерактивна** — сменить её цвет из её
   меню нельзя; значит «появление при смене цвета» в рантайме недостижимо и
   не проектируется (появление — только сбросом фильтра).
5. **Глобальный toggle поверх фильтра**: `_toggleNotes` при `_allNotes
   .length == 0` создаёт заметку `''` (extension.js:440) — этот путь тоже
   должен учесть активный фильтр (или остаться без фильтра по определению:
   нет заметок → нет и фильтра; но фильтр может быть активен при нуле
   заметок после удаления последней — край, зафиксирован в рисках 02).
