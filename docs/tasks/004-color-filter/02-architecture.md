# 02: Концепт — фильтр по цвету

Все решения ниже приняты пользователем 2026-10-21 (обсуждение идеи в чате).
Отклонённые альтернативы — в конце.

## 1. Семантика

- Фильтр — **один пресет** из `PRESET_COLORS`; мультивыбора нет.
- Строгое сравнение rgb-строк: заметка проходит фильтр ⇔ её `customColor`
  равен `rgb.join(',')` пресета. Категории «другое» нет — по состоянию UI
  цветов вне пресетов не существует (кастомный цвет удалён, дефолт = beige,
  01-анализ §Цвета).
- Повторный клик по активному свотчу снимает фильтр (toggle).

## 2. Состояние и время жизни

- Хранится в памяти `NotesManager` (`_colorFilter`: `null` | имя пресета).
- Переживает глобальный hide/show заметок в рамках сессии; переживает
  смену мониторов (фильтр не зависит от раскладок).
- Не пишется ни в gsettings, ни в layouts.json; `disable()`/перезапуск shell
  — фильтра нет (осознанно: фильтр — «покажи мне сейчас», а не настройка).

## 3. Инвариант видимости

> Заметка видима ⇔ `_notesAreVisible` ∧ заметка проходит фильтр
> (или `_colorFilter == null`).

- `_showNotes()` показывает только прошедших фильтр; `_onlyHideNotes()`
  прячет всех, как раньше. Все изменения видимости — только через
  `NoteBox.show`/`onlyHide` (input-регион, 01-анализ §Видимость).
- Применение фильтра к уже видимым заметкам: не прошедшие — плавное
  исключение (§5), прошедшие — без изменений. Снятие фильтра: все скрытые
  фильтром (при `_notesAreVisible`) показываются мгновенно.

## 4. UI: секция в меню панели

Порядок меню: New note → New from Clipboard → **секция фильтра** → Settings.

- Separator, затем заголовок «Фильтр по цвету» и свотчи 2×4 в порядке
  палитры (peach cream mint sky / lavender pink sage beige) — переиспользуем
  паттерн `NoteOptionsMenu` (menus.js:41–87): неинтерактивные пункты-строки
  с кнопками-свотчами `notesCircleButton`.
- Свотч активного фильтра обведён кольцом своего `ring`-цвета — тот же
  приём, что у текущего цвета заметки (menus.js:138–140).
- Под свотчами пункт «Сбросить фильтр», чувствителен только при активном
  фильтре.
- Клик по свотчу/сбросу закрывает меню (паттерн `_onApply`), результат
  виден сразу.

### Бейдж на панели

- При активном фильтре рядом с иконкой панели появляется маленькая цветная
  точка (цвет — `ring` пресета: темнее и контрастнее заливки на тёмной
  панели). Без фильтра точки нет.
- Реализация: ребёнок кнопки панели заменяется на контейнер
  [иконка, точка]; точка — маленький `St.Bin` с фоном. Точное
  позиционирование/размер — план (03).

## 5. Исключение заметки фильтром: плавный fade-out

Пользователь видит смену цвета заметки → её уход. Мгновенное исчезновение
читается как баг; поэтому:

1. `setEditMode(false)` (гасит редактирование, 01-анализ п.2);
2. `actor.ease({ opacity: 0, duration: ~300 мс, mode: EASE_OUT_QUAD })`;
3. по завершении: `onlyHide()` и возврат `opacity = 255`.

Появление (сброс фильтра, глобальный показ) — мгновенное: осознанно,
дезориентирует исчезновение, а не возврат. Анимации ввода не проектируем.

## 6. Новые заметки и активный фильтр

- «New note» и «New from Clipboard» при активном фильтре создают заметку
  цветом фильтра (`rgb.join(',')` вместо `''`); заметка сразу видима.
- Без фильтра — без изменений (`''` → `first-note-rgb`).
- Путь «нет ни одной заметки» (`_toggleNotes`, extension.js:440): при
  активном фильтре тоже цветом фильтра.

## 7. Смена цвета видимой заметки при активном фильтре

`applyColorAndSave` после применения цвета уведомляет менеджера; если
заметка видима и больше не проходит фильтр — §5 (плавное исключение).
Если фильтр не активен — поведение не меняется вовсе.

## Отклонённые альтернативы (с причинами)

- **Мультивыбор цветов** — перегруз UI и семантики, не нужно (решение
  пользователя).
- **Приглушение (dim) вместо скрытия** — текст read-only нечитаем,
  заметка продолжает ловить клики.
- **Подменю вместо секции** — лишний клик; пользователь выбрал секцию,
  видную сразу при открытии меню.
- **Хранение фильтра в gsettings/layouts.json** — фильтр — временное
  состояние сессии; «забытый» фильтр после перезагрузки скрывал бы заметки
  необъяснимо.
- **Категория «Другие цвета»** — цветов вне пресетов не существует (§1).
- **Кнопка скрытия отдельной заметки (крестик)** — смежная идея вне рамок
  задачи; перечислена как кандидат на будущее.

## Риски и принятые ограничения

- **Легаси-цвета вне палитры** в layouts.json (до редизайна): такая заметка
  не пройдёт ни один фильтр и будет скрыта при любом выборе. Принимается:
  UI давно не позволяет их создавать; по факту у пользователя таких нет.
  Спасение — сброс фильтра.
- **Забытый фильтр** («показал — а заметок половина»): компенсируется
  бейджем на панели и кольцом в меню; сброс перезапуском тоже работает.
- **Фильтр активен, заметок ноль** (удалили последнюю отфильтрованную):
  меню работает, «New note» создаёт цветом фильтра; бейдж остаётся. Край
  безмысленный, но консистентный.
