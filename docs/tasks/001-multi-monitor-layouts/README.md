# 001: Раскладки для нескольких мониторов

- Статус: реализация завершена (Ф0–Ф5); приёмка пройдена в X11 (сценарии 1–9), Wayland — ручная проверка, см. журнал в [04-progress.md](04-progress.md)
- ADR: [0001-multi-monitor-layout-registry](../../adr/0001-multi-monitor-layout-registry.md)
- Ветка: `feat/multi-monitor-layouts` (создаётся от актуального `dev`)

## Цель

Заметки корректно ведут себя при смене конфигурации мониторов: раскладка сохраняется на каждую конфигурацию, восстанавливается при её возврате, а при исчезновении мониторов заметки автоматически собираются в видимую зону (затем правятся руками).

## Пользовательский сценарий (приёмка)

1. Дом, 2 монитора: заметки разложены по вкусу → схема «дом».
2. Дорога, 1 экран: заметки вне экрана собраны в primary, правка → схема «дорога».
3. Офис, 2 монитора: сбор + правка → схема «офис».
4. Возврат домой → точное восстановление схемы «дом».
5. Отключение → восстановление схемы «дорога».
6. Возврат в офис → восстановление схемы «офис».
