## Цель

Работа с текстом заметки через контекстное меню (правый клик по текстовому полю,
в любом режиме) и клавиатуру: Копировать / Вырезать / Вставить / Undo / Redo /
Выделить всё — с корректной чувствительностью пунктов в режимах чтения и
редактирования, и с отменой последнего действия по Ctrl+Z в обоих режимах.

## Пользовательский сценарий (приёмка)

1. Выделить текст в заметке (в любом режиме) → правый клик по выделению →
   «Копировать» активен; выбор → текст в буфере, вставляется в стороннее
   приложение.
2. Правый клик по тексту без выделения → «Копировать» неактивен; «Вставить» и
   «Undo» — по состоянию (режим/буфер/история).
3. Режим редактирования → правый клик → «Вставить» активен (буфер непуст) →
   текст вставляется в текущую позицию курсора.
4. Режим чтения → «Вставить» в меню неактивен; Ctrl+V в read-only ничего не
   делает и не включает редактирование (решение 2026-10-21, отменяет
   поведение 8413260).
5. Набрать текст → Ctrl+Z отменяет набранную «порцию» одним шагом; повторный
   Ctrl+Z — предыдущую порцию; вставка кнопкой в заголовке тоже отменяется.
   Текст и файл на диске синхронны после каждой отмены.
6. Ctrl+Z работает и в режиме чтения (отмена вставки кнопкой заголовка,
   мутирующей текст в read-only).
7. Правый клик не сбивает выделение; меню закрывается по Esc/клику вне;
   скрытие или удаление заметки закрывает меню без ошибок в логе.
8. Две заметки одновременно: меню и истории отмен независимы.
9. Режим редактирования, есть выделение → «Вырезать» активен: текст удалён и
   в буфере; в режиме чтения пункт неактивен.
10. После отмены — Redo (Ctrl+Shift+Z или пункт меню) возвращает отменённое;
    любое новое изменение очищает redo.
11. «Выделить всё» выделяет весь текст в обоих режимах.
