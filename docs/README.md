# Документация изменений

Структура для работы над изменениями: анализ, концепции, решения (ADR), планы, прогресс.

```
docs/
  adr/                  Architecture Decision Records (решения уровня проекта)
  tasks/                Рабочие папки задач (папка = одна задача)
```

## Правила

- Одна задача = одна подпапка `tasks/NNN-slug/`. Номер сквозной, трёхзначный.
- Порядок чтения внутри задачи задаётся префиксами `01-`, `02-`, …
- ADR — только для принятых архитектурных решений. Рабочие материалы живут в задаче, ADR ссылается на них и наоборот.
- Статусы ADR: `proposed` / `accepted` / `superseded` (заменяется новым ADR, не удаляется).
- Формулировки краткие. Дублирование текста запрещено — ссылаться на файлы.
- Документы задачи не переписываются задним числом после реализации; изменения — новым разделом или в `progress.md`.

## Связанные места

- `AGENT.md` — правила git и рабочего процесса (ветки `feat/*`/`fix/*`, `--no-ff`).
- `.agent/` — рабочие заметки (палитра `COLOR.md`).
